# English Journey — A1 → B2

Painel estático, gratuito e sem dependências para acompanhar estudo autônomo de inglês com foco em **speaking**.

## Recursos
- Checklist diário com as 6 atividades do protocolo original (`English.md`), ajustadas às fases A1–A2 e B1–B2.
- Data selecionável, notas por dia, barra de conclusão, histórico recente e minutos registrados.
- Missões de fala sem roteiro, revisão de erros e desafio especial às sextas-feiras.
- Fontes gratuitas, marcos comunicativos e dicas de prática.
- Dados salvos **apenas no localStorage** do navegador; exportação/importação de backup JSON.

## Publicar no GitHub Pages
1. Após mesclar o pull request na branch `main`, vá em **Settings → Pages** neste repositório.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Selecione **main**, pasta **/(root)**, e clique em **Save**.
4. Acesse `https://lpraxedess.github.io/MyStudyinEnglish/` depois que a publicação for concluída.

O arquivo `index.html` não requer build, instalação, servidor, chave de API ou ferramenta paga. Para executar localmente, abra `index.html` no navegador. Para previsibilidade do armazenamento, use o endereço do Pages depois de publicado.

## Limitações importantes
- Não há sincronização entre dispositivos, contas ou nuvem. Limpar os dados do navegador, mudar de navegador ou usar aba privada pode apagar o progresso; faça backups.
- Concluir checklists não comprova nível CEFR. Use tarefas comunicativas e descritores oficiais; se possível, peça avaliação externa periodicamente.
- Minutos registrados representam tarefas marcadas como concluídas, não tempo cronometrado. O desafio oral da página não grava nem avalia sua voz.
- O estudo pode ser feito sem Speak, IA ou aplicativos pagos. Interação real com outras pessoas, mesmo em trocas gratuitas, ajuda a praticar alternância de turnos e pedidos de esclarecimento.

## Metodologia
Conservar a base do protocolo: **escuta compreensível, prática deliberada de fala, feedback seletivo e repetição**. A progressão A1 → B2 em ~24 meses é um objetivo, não uma promessa; revise-a conforme resultados e disponibilidade.
