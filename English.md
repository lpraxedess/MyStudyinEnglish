# ENGLISH — DAILY GUIDE
## 4 HORAS POR DIA

> Objetivo: todos os dias tocar em todas as habilidades importantes e fazer o conteúdo de um bloco alimentar o próximo.

---

## CHECKLIST DO DIA

- [ ] 1. CURSO — 60 min
- [ ] 2. INPUT — 45 min
- [ ] 3. ANKI — 15 min
- [ ] 4. GRAMÁTICA — 15 min
- [ ] 5. WRITING — 20 min
- [ ] 6. SHADOWING / PRONÚNCIA — 25 min
- [ ] 7. SPEAKING — 60 min

**TOTAL: 4h**

---

# 1. CURSO — 60 MIN

### Fazer

- [ ] Fazer as aulas planejadas do curso
- [ ] Entender o conteúdo
- [ ] Anotar somente dúvidas importantes
- [ ] Separar 3–5 expressões/frases úteis
- [ ] Separar 1–2 estruturas que quero aprender a usar
- [ ] Identificar vocabulário realmente relevante

### Não fazer

- [ ] Não anotar tudo
- [ ] Não tentar decorar tudo
- [ ] Não criar dezenas de cards

### Ao terminar

Tenho que sair daqui com:

**3–5 expressões + 1–2 estruturas + dúvidas importantes**

Esses elementos serão usados nos próximos blocos.

---

# 2. INPUT — 45 MIN

## Listening + Reading

Escolher conteúdo adequado ao meu nível.

### Primeira passagem — sem legenda

- [ ] Assistir/ouvir
- [ ] Tentar entender pelo contexto
- [ ] Identificar a ideia principal
- [ ] Perceber expressões que já conheço
- [ ] Perceber alguma expressão do curso

### Segunda passagem — legenda em inglês

- [ ] Rever o mesmo conteúdo
- [ ] Confirmar o que não entendi
- [ ] Identificar expressões naturais
- [ ] Observar como as estruturas são usadas
- [ ] Separar no máximo 3–5 itens realmente úteis

### Terceira passagem — sem legenda

- [ ] Rever/ouvir novamente
- [ ] Verificar se a compreensão melhorou
- [ ] Tentar acompanhar sem traduzir mentalmente

### Conexão com o curso

- [ ] Encontrei alguma expressão do curso?
- [ ] Vi alguma estrutura estudada?
- [ ] Entendi essa estrutura em outro contexto?

---

# 3. ANKI — 15 MIN

## Primeiro: revisar

- [ ] Fazer todas as revisões programadas

## Depois: adicionar

Adicionar no máximo:

**5 novos cards**

### Prioridade

1. [ ] Expressões importantes do curso
2. [ ] Expressões importantes do input
3. [ ] Erros importantes da escrita
4. [ ] Erros importantes da conversação

### Preferir

Frase completa + contexto.

**Exemplo:**

> I ended up working late.

Em vez de:

> end up = acabar

### Antes de adicionar cada card

Perguntar:

> "Isso é importante o suficiente para eu querer reconhecer/usar daqui a algumas semanas?"

Se não:

**não adicionar.**

### Objetivo

A maior parte dos cards deve testar:

**reconhecimento + compreensão**

Uma parte menor pode testar:

**produção**

A produção será treinada principalmente no Writing e Speaking.

---

# 4. GRAMÁTICA — 15 MIN

Não estudar gramática aleatoriamente.

Escolher algo que apareceu durante o dia.

### Fonte da dúvida

- [ ] Curso
- [ ] Input
- [ ] Anki
- [ ] Writing
- [ ] Speaking

### Fazer

- [ ] Entender a regra
- [ ] Ver alguns exemplos
- [ ] Criar 3–5 frases próprias
- [ ] Usar pelo menos uma dessas frases no Writing
- [ ] Tentar usar novamente no Speaking

### Pergunta principal

> "Eu consigo reconhecer essa estrutura?"

Depois:

> "Eu consigo produzir essa estrutura?"

---

# 5. WRITING — 20 MIN

## Produção

Escrever sem consultar o material.

### Meta

**100–150 palavras**

ou

**8–12 frases**

### Obrigatório tentar usar

- [ ] 2–4 expressões do curso
- [ ] 1–2 estruturas estudadas
- [ ] vocabulário do input
- [ ] ponto gramatical estudado

---

## Correção

Depois de escrever:

- [ ] Pedir correção à IA
- [ ] Identificar os erros mais importantes
- [ ] Entender por que estavam errados
- [ ] Reescrever as frases corrigidas

### Não fazer

Não transformar a correção em uma lista enorme de erros.

Selecionar:

**1–3 erros realmente importantes.**

### Depois

- [ ] Algum erro merece entrar no Anki?
- [ ] Algum erro precisa ser praticado no Speaking?
- [ ] Alguma dúvida precisa voltar para Gramática?

---

# 6. SHADOWING / PRONÚNCIA — 25 MIN

Usar preferencialmente um áudio do próprio Input.

## 5 min — Escutar

- [ ] Ouvir atentamente
- [ ] Observar ritmo
- [ ] Observar entonação
- [ ] Observar pronúncia
- [ ] Perceber ligação entre palavras

## 8 min — Repetir

- [ ] Ouvir uma frase
- [ ] Pausar
- [ ] Repetir
- [ ] Copiar ritmo e entonação

## 8 min — Shadowing

- [ ] Falar junto com o áudio
- [ ] Acompanhar o ritmo
- [ ] Não parar a cada palavra
- [ ] Tentar reproduzir a fala naturalmente

## 4 min — Gravar

- [ ] Gravar minha voz
- [ ] Comparar com o original
- [ ] Identificar 1 problema principal
- [ ] Repetir o trecho

### Foco do dia

Escolher apenas 1:

- [ ] Pronúncia
- [ ] Ritmo
- [ ] Entonação
- [ ] Connected speech
- [ ] Velocidade
- [ ] Sons específicos

---

# 7. SPEAKING — 60 MIN

## 15 MIN — CONVERSAÇÃO LIVRE

- [ ] Conversar espontaneamente
- [ ] Não consultar anotações
- [ ] Tentar explicar ideias
- [ ] Tentar manter a conversa
- [ ] Não interromper a cada erro

Objetivo:

**falar.**

---

## 15 MIN — SITUAÇÃO / CENÁRIO

Escolher uma situação:

- [ ] Trabalho
- [ ] Reunião
- [ ] Entrevista
- [ ] Viagem
- [ ] Restaurante
- [ ] Compras
- [ ] Conversa casual
- [ ] Explicar um problema
- [ ] Explicar uma ideia
- [ ] Defender uma opinião
- [ ] Fazer perguntas
- [ ] Resolver uma situação

Objetivo:

**usar inglês em uma situação real.**

---

## 15 MIN — REUTILIZAÇÃO

Agora pegar o conteúdo estudado hoje.

Usar deliberadamente:

- [ ] 3–5 expressões do curso/input
- [ ] 1–2 estruturas
- [ ] 1 ponto de gramática
- [ ] 1 correção do Writing

Não simplesmente repetir frases decoradas.

Criar situações diferentes.

Objetivo:

**transformar conhecimento passivo em ativo.**

---

## 15 MIN — FEEDBACK

Depois da conversa:

- [ ] Pedir os 3 erros mais importantes
- [ ] Identificar erros recorrentes
- [ ] Identificar palavras que faltaram
- [ ] Identificar estruturas que não consegui usar
- [ ] Identificar problemas de naturalidade
- [ ] Reformular as frases corrigidas
- [ ] Falar novamente as frases

# 10. SE ALGO DER ERRADO

## "Não entendi uma estrutura"

→ Gramática

## "Entendi, mas esqueço"

→ Anki + reutilização

## "Reconheço, mas não consigo falar"

→ Speaking

## "Sei falar, mas falo errado"

→ Feedback + repetição

## "Sei a palavra, mas não entendo quando alguém fala"

→ Input + Listening

## "Entendo, mas minha pronúncia está ruim"

→ Shadowing

## "Consigo falar, mas travo"

→ Speaking livre + recuperação espontânea

## "Sempre cometo o mesmo erro"

→ Grammar + Writing + Speaking + Anki

# 13. PAINEL SEMANAL

No final da semana:

## Listening

- [ ] Estou entendendo mais sem legendas?
- [ ] Estou reconhecendo mais palavras automaticamente?
- [ ] Estou acompanhando melhor a velocidade?

## Vocabulary

- [ ] Estou reconhecendo expressões mais rapidamente?
- [ ] Estou usando parte do vocabulário novo?
- [ ] Estou esquecendo alguma expressão importante?

## Grammar

- [ ] Os erros recorrentes diminuíram?
- [ ] Consigo usar as estruturas sem pensar tanto?

## Speaking

- [ ] Estou falando por mais tempo?
- [ ] Estou travando menos?
- [ ] Estou recuperando palavras mais rapidamente?
- [ ] Estou usando estruturas novas espontaneamente?

## Pronunciation

- [ ] Minha pronúncia está mais clara?
- [ ] Meu ritmo está mais natural?
- [ ] Minha entonação está melhor?

## Writing

- [ ] Os mesmos erros continuam aparecendo?
- [ ] Minha capacidade de formar frases melhorou?

# 14. REGRA DE PRIORIDADE

Quando faltar tempo, não abandonar sempre as mesmas áreas.

Prioridade:

1. **Speaking**
2. **Listening / Input**
3. **Curso**
4. **Revisão / Anki**
5. **Writing**
6. **Grammar**
7. **Shadowing**

Mas, em um dia normal:

**FAZER AS 7 ETAPAS.**

---

# 15. REGRA PRINCIPAL

Não terminar o dia apenas tendo estudado.

Terminar o dia tendo:

**aprendido → reconhecido → revisado → entendido → escrito → pronunciado → falado → corrigido → reutilizado.**
